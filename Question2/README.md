# Question 2 -- Natural Language Processing

This folder contains the R scripts, datasets and supporting documentation for the natural language processing analysis, including topic modelling and visualisations.
## Overview
This analysis applies Natural language processing (NLP) techniques to 10 news articles using RStudio.

## Methodology
The news articles were imported and preprocessed through text cleaning, tokenisation and removal of stop words.

LDA topic modelling was applied to identify three underlying topics within the document collection.

## Results and Visualisations
- Identified frequently occurring terms within each topic.
- Generated word-frequency visualisations and word clouds.
- Assigned a dominant topic to each news article.

## Interpretation
The analysis demonstrates how NLP and topic modelling can identify recurring themes and organise unstructured text into meaningful categories.
